# GURU Home Tutors Services

A responsive, mobile-first website for GURU Home Tutors Services.

## Deploy with GitHub Pages
1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then Save.
4. The site will publish at https://atelierog.github.io/guru-home-tutor-services/ after GitHub Pages finishes its first build.
